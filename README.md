# Egg Counter 🥚

A simple web app for counting eggs.

## Features
- Add or remove eggs one at a time, or by the dozen
- See the total as dozens + leftover eggs
- Daily log of how many eggs were collected each day
- Data is saved in your browser (localStorage), so it survives page reloads
- Works on phones and desktops

## Run it
No build step needed. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
